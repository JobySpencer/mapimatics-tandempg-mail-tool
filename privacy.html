Privacy policy

Mapimatics TandemPG Mail Tool (test) · operated by Mapimatics Consulting · last updated 2026-10-08

Who this applies to

This policy covers the Mapimatics TandemPG Mail Tool (test), a development test of a workflow tool used privately by its developer and the small business it is being built for. It is not offered to the general public.

Google data the tool accesses

When a person signs in with Google, the tool asks for two permissions:

  • Gmail: manage drafts (gmail.compose). The tool uses this only to create draft emails in the signed-in person's own account. Google describes this permission as covering drafts and sending, but the tool never sends email and never reads the inbox or any existing message. A person reviews each draft and sends it from Gmail.
  • Google Drive: files created by the tool (drive.file). The tool uses this only to create folders in the signed-in person's own Drive. It cannot see other files in that Drive.

Separately, the Drive owner may share one folder with a service account that the tool uses to read photos stored there. That account is read-only and can see only that folder and what is inside it.

How the data is used

  • Draft content (a short text and photos chosen by a person) is written to a Gmail draft in the signed-in person's account.
  • Customer folders are created in the signed-in person's Drive. Each folder's name and a few properties (such as the customer's name, email address and flight date) are stored on the folder itself, in that person's Drive.
  • Photos in the shared folder are read so that a person can pick which ones to attach.
  • In later versions, text and downscaled photos may be sent to an AI model hosted on Microsoft Azure in the United States to suggest email wording and photo choices. This is not active yet.

Data is used only to provide these features, which are visible in the tool's interface. It is not used for advertising, profiling, or credit decisions.

Storage and retention

  • The tool stores a sign-in token (a refresh token) so it can act on the person's behalf without asking again. Today it is kept in a private file on the developer's computer; later versions are planned to keep it in Azure Key Vault.
  • The tool does not keep copies of photos, emails or draft text. Photos are fetched when needed and discarded after use.
  • Everything the tool creates lives in the signed-in person's own Google account, under their control.

Sharing and human access

  • Google user data is not sold or shared with advertisers or data brokers.
  • It is transferred only to provide the features above, which in later versions includes the Azure-hosted AI model acting as a service provider, and where required by law.
  • People at Mapimatics Consulting do not read your Google data except with your explicit permission, to investigate a security problem, or to comply with the law.

Google API Services User Data Policy

The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and deleting data

  • You can revoke the tool's access at any time at myaccount.google.com/permissions. Revoking deletes the tool's ability to act in your account.
  • Drafts and folders the tool created stay in your Gmail and Drive until you delete them yourself.
  • To ask for the stored sign-in token or any related record to be deleted, email the address below.

Children

The tool is not directed at children and is not offered to them.
